Guia Rápido: rode um 30B em 5 minutos

O caminho mais curto do zero até um modelo local funcionando na sua máquina.

Passo 1 — Instale o Ollama

curl -fsSL https://ollama.com/install.sh | sh

Ollama gerencia download, quantização e GPU (CUDA, ROCm, Vulkan, Apple Silicon) automaticamente.

Passo 2 — Baixe o modelo

ollama pull qwen3.8:27b

Ou qualquer GGUF: ollama pull unsloth/qwen3.8-27b-gguf:q4_k_m — quantizações menores (q3/q4) cabem em menos VRAM.

Passo 3 — Rode

ollama run qwen3.8:27b

Pronto. Chat interativo na linha de comando. Para API local: curl http://localhost:11434/v1/chat/completions

Passo 4 — Otimize para seu hardware

SituaçãoAjuste
Pouca VRAM (8-12GB)Use q3_k_m, reduza contexto (OLLAMA_CONTEXT_LENGTH=16384)
CPU-only, 32GB RAMRode em CPU com threads altos — espere 2-5 tok/s
GPU AMD (Linux)Ollama usa Vulkan — verifique ollama ps p/ confirmar offload
Quer mais contexto27B + 40GB VRAM → contexto 131K+ sem problema
Máquina de trabalhoNunca use --reserve-vram 0; deixe 20% da VRAM livre

Alternativas ao Ollama

  • llama.cpp — mais controle, menor overhead, GGUF nativo
  • LM Studio — GUI amigável para iniciantes (Windows/Mac)
  • MLX (Mac) — melhor performance em Apple Silicon
  • vLLM — produção, alta concorrência, exige GPU forte
