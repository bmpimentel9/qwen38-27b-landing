Hardware Local

O que você precisa para rodar um modelo de 30B na sua máquina — do mínimo viável ao topo de linha.

Regra de ouro (quantização GGUF Q4)

Um modelo de ~27B em Q4_K_M ocupa ~16-17 GB de memória. Para rodar confortável:

NívelHardwareVelocidade estimadaModelos suportados
Mínimo32GB RAM (CPU-only, llama.cpp)2-5 tok/sAté 14B confortável, 27B lento
RecomendadoRTX 4060/4070 12-16GB20-40 tok/sQwen3.8-27B Q4
Recomendado+RTX 3090/4090 24GB40-70 tok/s27B Q6/Q8, 32B Q4
TopoAMD Strix Halo (Radeon 8060S, 40GB)60-90 tok/s27B/32B folgado + contexto longo
MacApple Silicon M-series 48-64GB30-60 tok/s27B Q4/Q6 via MLX

Referência: AMD Strix Halo (a máquina deste portal)

Setup real

Ryzen AI MAX+ 395 · Radeon 8060S

122GB RAM unificada, 40GB VRAM dedicados à iGPU. Roda Qwen3.8-27B inteiro na VRAM com contexto de 131K+, deixando RAM sobrando.

GPU: Radeon 8060SVRAM: 40GB
Runtime: Ollama + Vulkan~60-90 tok/s

Dicas rápidas

  • GPU com 16GB VRAM é o ponto de corte para 27B Q4 sem offload.
  • Sem GPU dedicada? 32GB RAM dá pra rodar 27B em CPU, mas espere 2-5 tok/s.
  • Contexto longo (262K) consome mais memória: reduza para 32K se faltar VRAM.
  • Use GGUF Q4_K_M como ponto de partida — melhor custo/benefício.
  • NVIDIA + CUDA ainda é o caminho mais simples; AMD via Vulkan (Ollama) funciona bem no Linux.
