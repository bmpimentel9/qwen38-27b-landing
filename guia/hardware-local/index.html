Resumo Rápido de Requisitos

Recomendado: RTX 4090/5090 (24GB) ou Mac com 32GB+ de memória unificada — roda GGUF 4 bits a ~17GB de VRAM. É o melhor custo-benefício para rodar o Qwen3.8-27B localmente.

O Qwen3.8-27B é um modelo denso de 27B. Ao contrário de modelos MoE, todos os 27 bilhões de parâmetros são carregados na memória. Com quantização de 4 bits (Q4_K_M), o modelo cabe em uma GPU de consumidor com 24GB de VRAM.

Atenção ao KV cache: Os valores acima são apenas dos pesos. A 262K de contexto, o KV cache pode consumir tantos GB quanto o modelo. Planeje 4–8GB extras de VRAM para o cache.

Setups Recomendados por Tier

Tier Mínimo — GGUF 4 bits (~17GB VRAM)

  • GPU: RTX 4090 24GB, RTX 5090 32GB, ou Strix Halo (128GB unificados)
  • RAM: 32GB de sistema
  • Armazenamento: 20GB livres (modelo + cache)
  • Contexto: 32K–64K prático (com folga para KV cache)
  • Throughput esperado: 10–30 tok/s (depende do hardware)
  • Custo: ~R$ 12.000–18.000 (GPU nova)

Tier Recomendado — GGUF 5 bits ou FP8 (~27GB VRAM)

  • GPU: RTX 5090 32GB, ou 2× RTX 3090 (48GB combinados)
  • RAM: 64GB de sistema
  • Contexto: 128K–262K (com folga para KV cache largo)
  • Throughput esperado: 15–40 tok/s
  • Custo: ~R$ 15.000–25.000 (GPU usada) ou ~R$ 35.000+ (nova)

Tier Entusiasta — BF16 (~54GB VRAM)

  • GPU: A100/H100 80GB, ou 2× RTX 6000 Pro
  • RAM: 128GB de sistema
  • Contexto: 262K nativo completo
  • Qualidade: máxima, sem perdas de quantização
  • Custo: ~R$ 50.000–150.000+

Tier Blackwell — NVFP4 (24,6 GiB)

  • GPU: Blackwell (RTX 5090 ou superior)
  • Contexto: 1M completo com 6,6M tokens de KV
  • Requer vLLM 0.27.1 ou superior
  • Otimizado para contexto máximo em GPU única

Rodando no Mac (Apple Silicon)

O Qwen3.8-27B roda bem em Macs com Apple Silicon, graças à memória unificada e ao suporte MLX. A Ollama oferece qwen3.8:27b-mlx otimizado para Apple Silicon.

Rodando em CPU (não recomendado)

É tecnicamente possível rodar o Qwen3.8-27B em CPU com llama.cpp, mas o throughput é de ~1–3 tokens/s — inviável para uso interativo. Considere apenas para testes ou se você tem um servidor com RAM abundante (64GB+) e muita paciência.

Dicas de Configuração

Contexto e KV Cache

O Qwen3.8-27B tem 262K de contexto nativo, mas o KV cache a esse tamanho consome tanta VRAM quanto o modelo. Para uso interativo, comece com --ctx-size 32768 e aumente conforme a VRAM disponível.

Offload de Camadas

No llama.cpp, --n-gpu-layers 99 carrega todas as camadas na GPU. Se VRAM for insuficiente, reduza este valor para fazer offload parcial para CPU/RAM.

Sampling

No modo thinking, use: temp 1.0, top_p 0.95, top_k 20. No modo instruct: temp 0.7, top_p 0.80, repetition_penalty 1.5. NUNCA use temperature=0 no modo thinking.

Throughput Medido

Em ASUS ROG Flow Z13 (Strix Halo, Radeon 8060S, 128GB unificados) com Ollama sobre Vulkan, Q5_K_M: 10,6 tok/s de decode. Um relato no Hacker News cita ~700 tok/s de prefill e ~30 tok/s de decode em hardware semelhante.
