RX 9060 XT 16 GB para LLM local: Linux ou Windows?

Hardware·Bruno Pimentel·1 set 2026·10 min de leitura

A RX 9060 XT de 16 GB tem custo por GB atraente para LLM local, mas o sistema operacional muda a recomendação. Linux com ROCm 7.2.1 é o caminho oficial mais completo; WSL é uma alternativa suportada, enquanto Windows nativo ainda exige aceitar limitações ou recorrer ao Vulkan.

Resposta curta: a RX 9060 XT de 16 GB vale ser considerada para LLM local quando você aceita Linux com ROCm 7.2.1 ou WSL. Em Windows nativo, ela não é hoje a escolha sem atrito: o Ollama não inclui a RX 9060 XT em sua lista AMD/ROCm para Windows, e a AMD limita o suporte Windows a PyTorch, não ao stack ROCm completo. Vulkan permanece como rota genérica em Windows e Linux, mas este artigo não mede seu desempenho.

O ponto decisivo não é apenas ter 16 GB de VRAM. Para uma GPU AMD, a combinação entre placa, sistema operacional, runtime e backend define se a instalação seguirá um caminho oficialmente documentado ou dependerá de uma alternativa mais genérica. A mesma RX 9060 XT pode ser uma compra defensável em Linux e uma fonte de atrito em Windows nativo.

Isso também muda a forma correta de comparar preço. Na fotografia de dois anúncios da Pichau em 1º de setembro de 2026, uma RX 9060 XT de 16 GB custava menos por GB que uma RTX 5060 Ti de 16 GB. A diferença é relevante, mas não compra automaticamente a mesma compatibilidade de software. O desconto da AMD remunera, em parte, a disposição do usuário para escolher o ambiente certo e lidar com um ecossistema mais específico.

O que os 16 GB entregam — e o que não resolvem

A ficha oficial da AMD identifica a RX 9060 XT como uma GPU RDNA 4, alvo gfx1200, com 16 GB de GDDR6. A memória usa barramento de 128 bits a 20 Gbps, resultando em largura de banda de 320 GB/s. O TBP informado é de 160 W; a recomendação de fonte é 450 W, com um conector de alimentação de oito pinos.

ItemEspecificação oficialImpacto na decisão
Arquitetura / alvoRDNA 4 / gfx1200Exige suporte do backend e do runtime
VRAM16 GB GDDR6Teto inicial para pesos, cache e buffers
Barramento / velocidade128-bit / 20 Gbps320 GB/s de largura de banda oficial
InterfacePCIe 5.0 x16Compatibilidade física e de plataforma
Energia160 W TBPFonte recomendada de 450 W
Conector1× 8 pinosInstalação elétrica simples para a categoria

Esses 16 GB não ficam integralmente disponíveis para o arquivo do modelo. O runtime ainda precisa acomodar contexto, cache, buffers e outras alocações. Por isso, “o GGUF tem menos de 16 GB” não equivale a “o modelo roda confortavelmente em 16 GB”. A margem depois dos pesos é tão importante quanto o tamanho nominal da placa.

A largura de banda também não autoriza uma previsão de tokens por segundo isoladamente. Quantização, contexto, backend, versão do runtime, processamento do prompt e geração influenciam o resultado. Sem uma medição controlada na RX 9060 XT, este artigo não publica expectativa de desempenho.

O que cabe do Qwen3.8-27B em 16 GB

Usando os tamanhos já publicados no portal para o Qwen3.8-27B, a RX 9060 XT entra na mesma decisão de outras placas de 16 GB: quants menores deixam margem operacional; quants próximas do limite nominal podem carregar no papel e falhar na prática. A tabela abaixo subtrai apenas o tamanho do arquivo de 16 GB. Ela não representa VRAM livre real.

QuantizaçãoTamanho publicadoDiferença para 16 GBLeitura prática
UD-IQ2_M10,32 GB5,68 GBMaior margem entre as opções listadas
UD-Q3_K_XL13,44 GB2,56 GBMargem mais estreita para o restante
IQ4_XS15,71 GB0,29 GBNão é uma configuração confortável
Q4_K_M17,11 GB−1,11 GBNão cabe integralmente na VRAM
Arquivo não é consumo total: os 5,68 GB ou 2,56 GB da tabela são diferenças aritméticas, não garantia de memória disponível. O sistema ainda precisa acomodar cache, buffers e overhead do runtime. Se a visão for usada, o mmproj acrescenta 0,93 GB aos artefatos necessários.

A IQ4_XS ilustra o problema: 15,71 GB deixam apenas 0,29 GB antes de qualquer outra alocação. Tratar essa linha como “cabe em 16 GB” produziria uma recomendação enganosa. Já a Q4_K_M, com 17,11 GB, exige offload parcial ou outra distribuição de memória, porque os pesos não entram integralmente na placa.

Para explorar essa conta em mais detalhes, consulte a configuração do Qwen3.8-27B em 16 GB e a tabela de quantização GGUF por GPU. O guia de hardware para LLM local ajuda a comparar a placa com outras faixas de VRAM.

Linux, WSL ou Windows: onde a RX 9060 XT faz sentido

Em 1º de setembro de 2026, a documentação separava claramente os três caminhos. A escolha mais completa era Linux; WSL oferecia uma ponte oficialmente listada; Windows nativo permanecia limitado para quem deseja usar o ecossistema ROCm de forma ampla.

AmbienteEstado documentadoDecisão
LinuxRX 9060 XT listada no ROCm 7.2.1 e no Ollama com ROCm v7Melhor caminho oficial
WSLRX 9060 XT e PyTorch 2.9.1 listados no ROCm 7.2.1Alternativa válida
Windows nativo + ROCm/OllamaOllama não lista a 9060 XT; AMD oferece PyTorch, não o stack completoNão é opção sem atrito
Windows ou Linux + VulkanRota adicional documentada por Ollama e llama.cppPlano B genérico, sem promessa de desempenho

Linux: caminho recomendado

A matriz Linux do ROCm 7.2.1 lista oficialmente a RX 9060 XT, com PyTorch 2.9.1 em nível de produção. Entre os sistemas documentados estão Ubuntu 24.04.4, Ubuntu 22.04.5 e RHEL 10.1. A documentação de GPU do Ollama exige ROCm v7 no Linux e inclui a RX 9060 XT na lista compatível.

Para quem aceita instalar uma distribuição suportada e manter o stack alinhado às versões documentadas, esse é o cenário com menos ambiguidade. “Linux” aqui não significa qualquer distribuição ou versão: a recomendação se limita às combinações indicadas pela matriz do ROCm 7.2.1.

WSL: compromisso para quem precisa do Windows

A matriz WSL do ROCm 7.2.1 também lista a RX 9060 XT e PyTorch 2.9.1. Isso torna o WSL uma opção intermediária para o usuário que precisa manter o Windows como sistema principal, mas aceita executar a carga de IA dentro do ambiente Linux.

O suporte listado não transforma WSL e Linux nativo na mesma experiência. Esta análise não mediu instalação, estabilidade, consumo de memória ou desempenho nos dois ambientes. A conclusão é apenas de compatibilidade documentada: a GPU aparece nas matrizes de ambos.

Windows nativo: onde está o atrito

No Windows, a lista AMD/ROCm do Ollama menciona famílias RX 7900, 7800, 7700 e 7600, mas não a RX 9060 XT. Ao mesmo tempo, a documentação Windows da AMD informa que apenas PyTorch está disponível, não o stack ROCm completo, e registra batch de LLM igual a 1.

Isso não significa que toda execução seja impossível. Significa que a RX 9060 XT não deve ser vendida como escolha plug-and-play para Ollama com ROCm no Windows nativo. Quem não quer Linux, WSL nem experimentação com Vulkan deve considerar essa lacuna antes de economizar na compra.

Vulkan é a rota genérica — não um benchmark

O Ollama documenta suporte adicional via Vulkan em Windows e Linux. O guia de build do llama.cpp também oferece backends HIP e Vulkan. Para Windows, a compilação Vulkan documentada usa:

cmake -B build -DGGML_VULKAN=ON
cmake --build build --config Release

No Linux, o mesmo backend pode ser habilitado com:

cmake -B build -DGGML_VULKAN=1
cmake --build build --config Release

Esses são comandos de documentação, não comandos executados durante a produção deste artigo. Eles mostram que existe uma rota disponível; não demonstram velocidade, estabilidade ou paridade com ROCm. O próximo passo responsável é compilar, registrar versões e medir separadamente processamento do prompt e geração.

Se você ainda está escolhendo runtime, veja o guia de execução local. Para uma visão mais ampla do ecossistema AMD, o artigo sobre o Lemonade SDK com GPU e NPU AMD cobre outra intenção; esta página decide especificamente a RX 9060 XT por sistema operacional e backend.

Preço: bom custo por GB em dois anúncios específicos

Na consulta pontual à Pichau em 1º de setembro de 2026, a ASUS RX 9060 XT Dual 16 GB aparecia por R$ 3.389,99 no Pix, enquanto a MSI RTX 5060 Ti Ventus 16 GB aparecia por R$ 4.599,99 no Pix. São dois SKUs específicos, não uma média de mercado.

ASUS RX 9060 XT DualR$ 3.389,9916 GBR$ 211,87/GB

Nesse recorte, a RX custava R$ 1.210,00 menos, uma diferença de 26,3% sobre o preço da RTX. Vista no sentido inverso, a RTX era 35,7% mais cara que a RX. As duas formas de expressar o percentual usam bases diferentes; por isso não devem ser tratadas como números intercambiáveis.

O custo por GB favorece a RX, mas capacidade não resume compatibilidade. Para um usuário confortável com Linux ou WSL, a economia pode justificar a escolha. Para quem exige Windows nativo com o caminho mais previsível possível, comparar apenas R$/GB esconde justamente o principal custo: o atrito de software.

A recomendação final é condicional: a RX 9060 XT é uma opção de 16 GB com bom custo por GB para quem aceita organizar o software em torno da placa. Linux com ROCm 7.2.1 é o caminho principal; WSL é o compromisso mais razoável. No Windows nativo, a placa deixa de ser uma escolha simples e passa a ser uma escolha de experimentação.

O que esta análise não conclui

  • Não há benchmark da RX 9060 XT neste artigo. Nenhuma taxa de prefill, decode ou latência foi medida.
  • Os comandos Vulkan não foram executados. Eles reproduzem a forma documentada de habilitar o backend.
  • Os preços são uma fotografia de dois SKUs. Não representam todo o mercado brasileiro nem permanecem válidos indefinidamente.
  • Tamanho do GGUF não é VRAM total. Cache, buffers, contexto e runtime consomem memória adicional.
  • Compatibilidade documentada não garante ausência de bugs. Sistema, driver, runtime e modelo precisam permanecer alinhados.
  • Esta pauta não avalia licenças. A decisão tratada aqui é hardware, sistema operacional e runtime.

Próximo passo: escolha primeiro o ambiente

  1. Se você aceita Linux, escolha uma versão listada na matriz ROCm 7.2.1 e confirme o suporte da RX 9060 XT antes da instalação.
  2. Se precisa manter Windows, avalie WSL antes de assumir compatibilidade equivalente no Windows nativo.
  3. Se optar por Vulkan, compile o llama.cpp com o backend documentado e registre GPU, driver, sistema, versão do runtime, modelo, quantização e contexto.
  4. Ao medir, separe prompt processing de geração e faça mais de uma execução. Só então compare com outro backend.

Para a escolha de quantização, parta de uma opção que deixe margem real, não apenas alguns megabytes nominais. Em uma placa de 16 GB, a decisão mais robusta começa pela pergunta “quanto sobra para o runtime?” — não por “qual é o maior arquivo que quase cabe?”.

Perguntas frequentes

A RX 9060 XT de 16 GB é boa para LLM local?

Ela vale ser considerada pelo custo por GB quando o usuário aceita Linux com ROCm 7.2.1 ou WSL. Não há benchmark próprio neste artigo, portanto a recomendação é de compatibilidade e capacidade, não de velocidade.

A RX 9060 XT funciona com Ollama no Windows?

Em 1º de setembro de 2026, a lista AMD/ROCm do Ollama para Windows não incluía a RX 9060 XT. O Ollama documenta Vulkan como suporte adicional, mas isso não equivale ao caminho ROCm oficial nem comprova desempenho.

O Qwen3.8-27B cabe nos 16 GB da RX 9060 XT?

Depende da quantização. UD-IQ2_M e UD-Q3_K_XL ficam abaixo de 16 GB como arquivos; IQ4_XS deixa margem nominal de apenas 0,29 GB e não é confortável; Q4_K_M, com 17,11 GB, não cabe integralmente. Em todos os casos, é preciso reservar memória adicional para o runtime.

Linux ou Windows para usar a RX 9060 XT com IA local?

Linux é a recomendação principal porque a placa aparece nas matrizes do ROCm 7.2.1 e do Ollama Linux. WSL é a alternativa suportada para quem mantém Windows. Windows nativo exige aceitar um stack mais limitado ou experimentar a rota Vulkan.
