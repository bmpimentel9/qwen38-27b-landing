Best Local 30B Models (Aug/2026): 11 Worth the Download

The eleven worth the download — one verdict per use case, real measured VRAM, zero technical ties.

One model for each job: the eleven best local ~30B models

August 2026 was the month the community's question stopped being how to run a local model and became which local model to run. In 30 days the Muse Glimmer 30B (Aug 10), the Qwen3.8-27B (Aug 14) and the LTX-2.5 (Aug 17) shipped — and YouTube started answering "basically an Opus running locally". This page gathers the eleven candidates for your VRAM in August/2026 — the six classics plus the rivals the community already compares (GLM-4.7-Flash, Nemotron Cascade 2, Gemma 4 31B and Apriel 1.6) and the Qwen3-Coder-30B-A3B — with the source behind every number. The editorial rule is a single one: if it does not fit on your machine, it is not the best model for you.

The quick answer

What is the best local 30B model in August/2026? It depends on the job — and the dependency is literal, not a dodge:

  • Coding and agentic engineering: Qwen3.8-27B — LiveCodeBench 90.3, SWE-bench Pro 61.7, DeepSWE 42.2 (official model card)
  • 24/7 agent with tools (MCP): Muse Glimmer 30B — MCP Atlas 75.5, the tool-calling benchmark the others did not even publish
  • 12–16 GB GPU: GPT-OSS-20B — GGUF of 11.27 GiB, 3.6B active per token
  • Vision and documents: Qwen3.8-27B again — MathVision 94.6, OmniDocBench 91.1, native vision in the GGUF
  • 256K+ context on a single GPU: Qwen3.8-27B (262,144 native). 1M tokens with 110 GB+ of RAM: DeepSeek V4 Flash
  • Proven previous generation: Qwen3.6-27B stays relevant — same body as the 3.8, loses 26 of 26 benchmarks, but keeps the documented Thinking Preservation
  • Rivals from other houses: the GLM-4.7-Flash (3B active, agentic), the Nemotron-Cascade-2-30B-A3B (LCB challenger at 87.2), the Gemma 4 31B (Google's dense, GPQA 84.3), the Apriel-1.6-15b-Thinker (7.91 GB — the option that fits 12 GB) and the Qwen3-Coder-30B-A3B (SWE-bench Verified 51.6, 3.3B active, the most downloaded in the market) — the number-by-number matchup is in Qwen3.8-27B vs the 30B rivals.
The outlier of the list. The DeepSeek V4 Flash is not a 30B: 284B total parameters and a 92–103 GB GGUF. It is here because it activates only 13B per token — the compute cost per token of a 13B — and because 1M of native context is territory no ≤30B reaches. If your criterion is "fits in the GPU", skip it; if it is "fits in 110 GB+ of unified memory", it becomes the candidate for the best no-new-hardware buy on the list.

Verdict: coding & engineering — Qwen3.8-27B

Qwen3.8-27B winner

Across the four agentic-coding benchmarks the model card publishes against the previous generation, a sweep: SWE-bench Pro 61.7 (3.6 scored 53.5; Opus 4.6 Max, 53.4), DeepSWE 1.1 42.2 (was 13.3 — 3.2× the score), QwenSWEBench 79.0 (was 49.3), Terminal-Bench 2.1 73.0 (was 63.4). LiveCodeBench v6: 90.3.

The community confirmed it in production, not in theory prompts: in the r/LocalLLaMA launch threads, a cybersecurity analyst called the model a watershed; another user stood up a complete e-commerce store on vercel.app written by the model; a third started writing ray-tracers in BASIC against the 3.6. On YouTube, WorldofAI summed it up: "basically an Opus running locally".

The caveat this portal always makes: these numbers are from Qwen's official model card, without independent reproduction — the industry standard, and the same criterion applies to every vendor here. What does exist independently: the Artificial Analysis Intelligence Index v4.1.1 (measured over 160M output tokens) gave the 27B a score of 52 — tied with GPT-5.6 Luna (max), one point behind the 1.7T DeepSeek V4 Pro 0813, and first among 135 open weights up to 40B.

Starting config (full recipe in the run guide (PT-BR)): llama-server -hf unsloth/Qwen3.8-27B-GGUF:IQ4_XS --ctx-size 32768 --n-gpu-layers 99 --flash-attn on. For SWE with a large context, the 256K on 24 GB guide (PT-BR) has the measured step-by-step.

Verdict: agents & computer use — Muse Glimmer 30B

Muse Glimmer 30B winner in tools · Qwen3.8-27B winner in computer

Agents is not a single category — and the two model cards split the territory with almost rehearsed precision.

For a 24/7 tool agent — MCP tool calling, deep search, routine automation — the Muse Glimmer was purpose-built: distilled from Muse Spark by Meta, 100+ languages, built-in vision and Apache 2.0 with no gate. The number that matters: MCP Atlas 75.5 on Meta's official table, against 62.5 for Qwen3.6-27B and 54.2 for Gemma4-31B. DeepSearch QA 74.6. The Qwen3.8-27B simply did not publish those benchmarks — you cannot claim who would win.

For an agent that operates the computer — clicking, typing, navigating — the Qwen3.8-27B plays in another league: OSWorld-Verified 84.3 against 65.9 for the Muse, WebArena 64.8, AndroidWorld 81.9. And the Muse's throughput bonus: the DFlash drafter (1.63 GB) triples generation on the 5090 — from 74.9 to 233.4 tok/s (3.1×) — which changes the math for an agent running all night.

Both at Q4 fit together in ~34 GB: tool agent + code agent in the same window is a documented setup in the dedicated Muse Glimmer article (PT-BR).

Verdict: vision & multimodal — Qwen3.8-27B, again

On the model card's vision benchmarks, the 3.8 runs over its own generation: MathVision 94.6 (with CI), CharXiv RQ 90.2, OmniDocBench 1.5 91.1 — and the generational jump BabyVision 85.6 against 28.9 for the 3.6, almost triple. In the GGUF, the mmproj that wires up vision costs 0.93 GB. The local proof already recorded on the portal: Simon Willison's bounding-box test (Aug 16) got both pelicans right on the first try, detecting from a GGUF, no vision API.

The Muse Glimmer is the honest runner-up: native ViT-G/14 with 4,096 visual tokens per image — screenshot and document reading built in, which is what a local agent needs. The Gemma 3 27B is the consolidated multimodal: vision at 128K and a mature ecosystem — but at 16.55 GB in Q4_K_M it costs more memory than the Muse Glimmer (15.88 GB) and its visual reasoning is a generation behind (MMMU val 64.9 on the official TR). The Gemma 4 31B (Mar/2026) enters the table as Google's dense that closes the GPQA gap (84.3) and has MMMU Pro 76.9 — another benchmark, another scale; a direct visual comparison with the Qwen's MathVision 94.6 does not exist on Google's card. Full guide: Qwen3.8-27B for vision and videos (PT-BR).

Verdict: weak hardware (12–16 GB) — GPT-OSS-20B

GPT-OSS-20B winner · Apriel-1.6-15b-Thinker 12 GB resident

GPT-OSS-20B remains the best for 16 GB: MXFP4 GGUF of 11.27 GiB (llama.cpp bench), 3.6B active per token, 131,072 context. OpenAI positions it: "similar to o3-mini on common benchmarks, on 16 GB devices". The Apriel-1.6-15b-Thinker debuts as the new resident of the 12 GB range: IQ4_XS of 7.91 GB, native LLaVA vision, BFCL v3 63.5 and AIME25 88 — competitive numbers for half the size. The two split the territory without cancelling each other: if it fits in 12 GB, Apriel; if it fits in 16 GB, GPT-OSS.

Official numbers (arXiv 2508.10925, Table 3): SWE-bench Verified 53.2 at reasoning medium, GPQA Diamond 66.0, MMLU 84.0. It is the score of a smaller model — and the gap to the 27Bs is real (GPQA 66.0 vs 89.2), but 11 GiB is 11 GiB. On a 12 GB RTX 3060 it runs with moderate context; the Qwen3.8-27B on the same card, via the 10.32 GB UD-IQ2_M, delivers ~9.7 tok/s.

Whoever has 16 GB and wants the quality ceiling: the Qwen3.8-27B on 16 GB guide (PT-BR) shows the full IQ4_XS in the GPU (~20 t/s on the 4070 Ti Super) with quantized KV cache and n-gram speculative decoding.

Verdict: long context (256K–1M) — Qwen3.8-27B, with DeepSeek in the wings

262,144 native tokens — double the Muse Glimmer, quadruple the Gemma 3 — and the architecture's cheap cache: only 16 of the 64 layers are full-attention (the other 48 are fixed-state Gated DeltaNet), so the Q4 KV cache of the entire context costs ~4.25 GiB. The documented production proof: 50.44 tok/s average with all 262,144 tokens enabled on a 24 GB GPU (RTX PRO 4000 Blackwell, piszczek.pl measurement, 10 runs).

DeepSeek V4 Flash is the other planet: 1,048,576 native tokens — 4× the Qwen — under an MIT license, the only open weight with 1M of context. With 13B active, the 103 GB UD-IQ3_XXS GGUF runs on a 128 GB Mac or a 122 GB Strix Halo. The caveats: a 103 GB download, a recommended minimum of 110 GB of total memory, and Think Max mode asking for 384K allocated. It is not a consumer-GPU model; it is a workstation model. The honest answer has two parts: 24 GB → Qwen3.8-27B; 110 GB+ of unified memory → DeepSeek V4 Flash.

Verdict: Brazilian hardware and cost

At local prices, a used RTX 3090 is still the best cost-benefit for a 27B at Q4: 41.5 tok/s on the Qwen3.8-27B, an InsiderLLM measurement with a public source. The Strix Halo (Ryzen AI MAX+ 395, 122 GB unified) is the most interesting local case: 17.3 tok/s on the 27B at Q4 — and the real entry door to DeepSeek V4 Flash, because 122 GB covers the 103 GB GGUF. Full per-hardware table: tokens per second on real hardware (PT-BR).

All of them are free and open-weight; the cost difference between them is the memory you already own. In a country where a 5090 costs the price of an entry-level car, "best local model" starts with a different question: how much memory is left on your machine?

Three honest observations about the matchup:

🔗 Qwen3-Coder-30B-A3B in the master table. The Coder is the most downloaded coding MoE in the market (11.9M GGUF/mo, 8.5M Ollama, 21/08/2026) — and it is in the master table above. The dedicated Qwen3.8-27B vs Qwen3-Coder-30B-A3B matchup is in the verdict article (PT-BR) (SWE-bench Verified 51.6, AAII est. 14, 3.3× the dense's throughput).
  • (a) Pure coding: Qwen3.8 leads, Cascade 2 is the real challenger. The 90.3 vs 87.2 gap on the LCB is ~3%, inside the order-of-magnitude margin — but the Qwen also publishes SWE-bench Pro (61.7) and DeepSWE (42.2), which the Cascade 2 does not cover. The Cascade 2 answers with AIME25 92.4 (98.6 with tools) and GPQA-D 76.1, territory where the Qwen also did not publish.
  • (b) Throughput and the 24/7 agent: the A3B MoEs (GLM-4.7-Flash, Nemotron Cascade 2) deliver 3–8× the dense's t/s on the same hardware, because they activate only ~3B of the 30B total. GLM publishes τ²-Bench 79.5, BrowseComp 42.8 and SWE-bench Verified 59.2 — autonomous-agent and web-navigation benchmarks the Qwen did not publish. The empirical Brazilian counterpoint: glukhov.org/pt ran the models on a structured migration task and recorded 100% error for GLM-4.7-Flash on the mapping task (and 96.3% for Cascade 2) — a reminder that model card ≠ production guarantee.
  • (c) The 12 GB range: the Apriel-1.6-15b-Thinker is the new resident. At 7.91 GB in IQ4_XS it fits on cards where the Qwen3.8-27B only enters at IQ2. Apriel publishes BFCL v3 63.5 (function calling), Tau2 Telecom 69 and AIME25 88 — competitive numbers for its size. GPT-OSS-20B loses the monopoly of the entry range but keeps the title at 16 GB thanks to its 131K context and 3.6B-active throughput.
⚠️ Watch out for benchmark versions. Apriel advertises AAII v3.0 57 — an earlier version of the Artificial Analysis Intelligence Index than the v4.1.1 where the Qwen3.8-27B scores 52. Do not put the two on the same line without noting the version. GLM publishes GPQA 75.2 without specifying "Diamond" — we cite it as "GPQA" (75.2), not "GPQA Diamond". Respecting the source is part of the transparency this page promises.

Methodology and transparency

Every number on this page has a named source: official model cards (Qwen, Meta, OpenAI/arXiv 2508.10925, DeepSeek, Google Gemma 3 TR arXiv 2503.19786, Google Gemma 4 card, Z.ai GLM-4.7-Flash, NVIDIA Nemotron-Cascade-2, ServiceNow Apriel-1.6), the portal's sources dossier (SOURCES-BENCHMARKS.md, extractions on 15/08, 19/08 and 20/08), own measurements on Strix Halo, and third-party measurements always attributed. Benchmarks from different vendors use different harnesses: every comparison between model cards is an order of magnitude, and it is labelled as such wherever it appears. No number was invented; estimates carry "~". Page reviewed on 21/08/2026 (addition of the 30B rivals, live HF API verification on 20/08) — if a model card changes, this table gets old, and that is how it should be.

Frequently asked questions

What is the best local 30B model overall?

The Qwen3.8-27B, if you have 16 GB or more of VRAM: it leads in coding (LiveCodeBench v6 90.3), computer use (OSWorld-Verified 84.3) and context (262,144 native tokens), with native vision and Apache 2.0. Numbers from Qwen's official model card; the existing independent check (Artificial Analysis Intelligence Index v4.1.1) scores it 52 — tied with GPT-5.6 Luna and #1 among 135 open weights up to 40B.

Muse Glimmer 30B or Qwen3.8-27B?

For a 24/7 tool agent (MCP, deep search): Muse Glimmer — distilled for it (MCP Atlas 75.5 vs 62.5 for Qwen3.6-27B on Meta's official table). For coding and computer use: Qwen3.8-27B (OSWorld-Verified 84.3; SWE-bench Pro 61.7). There is no official head-to-head between the two — the numbers come from model cards of different vendors.

Qwen3.8-27B or GLM-4.7-Flash?

It depends on the axis. In deep coding, vision and context the Qwen3.8-27B leads (LCB v6 90.3 vs 64.0 for GLM). In 24/7 agentic throughput, GLM-4.7-Flash is an A3B MoE with ~3B active (3–8× the dense's t/s), and published τ²-Bench 79.5, BrowseComp 42.8 and SWE-bench Verified 59.2 — benchmarks Qwen did not publish. There is no official head-to-head. Caveat: the empirical glukhov.org/pt test recorded 100% error for GLM on a structured migration task (OpenCode), reinforcing that a model card is not a production guarantee.

Is DeepSeek V4 Flash a 30B model?

Not in total parameters: 284B total, GGUF of 92 to 103 GB — it does not fit in a consumer GPU. But it activates only 13B per token: the compute cost per token is that of a 13B. It is on the page as an honest comparison for anyone with 110 GB or more of unified memory (Mac, Strix Halo), where it delivers 1,048,576 tokens of native context.

What is the best local model for a 16 GB GPU?

GPT-OSS-20B for speed and headroom (MXFP4 GGUF of 11.27 GiB, runs in 16 GB); Qwen3.8-27B at IQ4_XS (15.71 GB measured) for maximum quality that still fits — with quantized KV cache and speculative decoding, ~20 t/s on an RTX 4070 Ti Super.

Why is Gemma 3 27B on the list if it is a generation behind?

Because it is Google's 27B with native vision, a mature ecosystem and 16.55 GB at Q4_K_M — and because the honest comparison shows the size of the gap: GPQA Diamond 42.4 on the instruct (official Technical Report, Table 6) vs 89.2 for Qwen3.8-27B. The successor Gemma 4 31B (Mar/2026) closes that gap to 84.3 on GPQA Diamond — table above and the Qwen3.8 vs rivals section.

Do these models work offline?

All of them run 100% local via llama.cpp or Ollama — download the GGUF, unplug the router, keep working. No data leaves the machine; the only external dependency is the initial Hugging Face download.
