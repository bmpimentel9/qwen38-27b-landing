O que é o Qwen3.8-27B?

O que é o Qwen3.8-27B?

O Qwen3.8-27B é um modelo de linguagem de pesos abertos (licença Apache 2.0) desenvolvido pela equipe Qwen (Alibaba Cloud). É um modelo denso de 27 bilhões de parâmetros — todos ativos a cada token, ao contrário de MoE. Tem atenção híbrida (Gated DeltaNet + Gated Attention), 262.144 tokens de contexto nativo (1M com RoPE scaling) e multimodalidade nativa (texto, imagem, vídeo, documentos). Foi lançado em 14 de agosto de 2026.

Qual a diferença entre denso e MoE?

Modelo denso ativa todos os parâmetros a cada token (maior qualidade por parâmetro, menor velocidade). Modelo MoE (Mixture of Experts) ativa apenas uma fração dos parâmetros (menor qualidade por token, maior velocidade). O Qwen3.8-27B é denso; o Qwen3.6-35B da geração anterior é MoE (ativa ~3B de 35B). No mesmo hardware, o MoE entrega 5,3× mais tokens/s.

O que é atenção híbrida?

O Qwen3.8-27B usa um padrão que intercala 3 camadas de Gated DeltaNet linear (eficiente para contexto longo) com 1 camada de Gated Attention (raciocínio completo), repetido 16 vezes ao longo de 64 camadas. Isso permite processar 262K tokens sem estourar a memória com KV cache.

O que é multimodalidade nativa?

A torre de visão é nativa, não um adaptador adicionado depois. O modelo entende imagens, vídeos e documentos sem componentes adicionais. Benchmarks confirmam: MathVision 94,6 (matemática a partir de imagens), OmniDocBench 91,1 (leitura de documentos), CharXiv 90,2 (gráficos científicos).

Hardware e VRAM

Quanto de VRAM o Qwen3.8-27B precisa?

Depende da quantização:

  • GGUF 4 bits (Q4_K_M): ~14–17 GB — RTX 4090/5090, Strix Halo, Mac 32GB+
  • GGUF 5 bits (Q5_K_M): ~18–19 GB
  • GGUF 8 bits / FP8: ~27 GB — RTX 5090 32GB, 2× 3090
  • BF16 (sem perdas): ~54 GB — A100/H100 80GB
  • NVFP4 (Blackwell): 24,6 GiB — 1M de contexto em GPU única

Para detalhes completos, veja nosso guia de hardware.

O Qwen3.8-27B roda em RTX 3090?

Sim. A RTX 3090 tem 24GB de VRAM, suficiente para Q4_K_M (~17GB) com folga para KV cache. É o melhor custo-benefício para LLMs locais em 2026 — usada por ~R$ 3.500–4.500.

O Qwen3.8-27B roda no Mac?

Sim. Macs com Apple Silicon e 32GB+ de memória unificada rodam o Qwen3.8-27B via Ollama MLX (ollama run qwen3.8:27b-mlx) ou mlx-lm. MacBook Pro M4 Max (36/48GB), Mac Studio M2 Max (64GB) e Mac Studio M2 Ultra (128GB) são os recomendados.

Consigo rodar sem placa de vídeo (CPU only)?

Tecnicamente sim via llama.cpp, mas o throughput é de ~1–3 tokens/s — inviável para uso interativo. Considere apenas para testes ou com um servidor com 64GB+ de RAM.

Performance e Velocidade

Qual a velocidade do Qwen3.8-27B localmente?

Depende do hardware e quantização. Em ASUS ROG Flow Z13 (Strix Halo, Radeon 8060S, 128GB unificados) com Ollama sobre Vulkan, Q5_K_M: 10,6 tok/s de decode. Um relato no Hacker News cita ~700 tok/s de prefill e ~30 tok/s de decode em hardware semelhante.

Modelo denso é mais lento que MoE: o Qwen3.6-35B MoE entrega 56,6 tok/s no mesmo hardware — 5,3× mais rápido. O 27B denso é melhor como especialista chamado sob demanda.

O que é thinking mode?

O Qwen3.8-27B tem dois modos: Thinking (padrão, com raciocínio passo a passo visível) e Instruct (resposta direta sem raciocínio explícito). O thinking mode é controlado por reasoning_effort (xhigh, medium, low) e preserve_thinking (mantém contexto de raciocínio entre mensagens, ativo por padrão).

Como configurar sampling corretamente?

  • Thinking: temp 1.0, top_p 0.95, top_k 20
  • Instruct: temp 0.7, top_p 0.80, repetition_penalty 1.5
NUNCA use temperature=0 no thinking mode. O modelo entra em loop repetitivo.

Instalação e Uso

Como instalar o Qwen3.8-27B via Ollama?

ollama run qwen3.8:27b

Um comando puxa o modelo quantizado (18GB, 256K contexto, texto + imagem). Para o guia completo, veja como rodar o Qwen3.8-27B.

Como rodar via llama.cpp?

llama-cli -hf unsloth/Qwen3.8-27B-GGUF:Q4_K_XL \
  --ctx-size 262144 \
  --temp 1.0 --top-p 0.95 --top-k 20

Como rodar via vLLM?

vllm serve Qwen/Qwen3.8-27B \
  --max-model-len 262144 \
  --reasoning-parser qwen3

Requer vLLM ≥ 0.27.2.

Sobre o Modelo

Qual a licença do Qwen3.8-27B?

Apache 2.0 — permite uso comercial e modificação sem restrições. É uma das licenças mais permissivas do ecossistema de LLMs.

Quando o Qwen3.8-27B foi lançado?

Os pesos foram liberados em 14 de agosto de 2026 no Hugging Face (Qwen/Qwen3.8-27B). O anúncio da família Qwen3.8 ocorreu em 3 de agosto (Qwen3.8-Max via API); 11 dias depois os pesos do 27B foram publicados. Quantizações GGUF da Unsloth estavam disponíveis no mesmo dia.

Qual a família Qwen3.8?

  • Qwen3.8-27B — 27B denso · este modelo (pesos abertos, Apache 2.0)
  • Qwen3.8-2.4T-A95B — 2,4T MoE, ~95B ativos
  • Qwen3.8-Max — Flagship (API apenas, $2/$6/$0,25 cache)

O Qwen3.8-27B fala português?

Sim. Como modelo multilíngue treinado pela Qwen, o Qwen3.8-27B compreende e gera texto em português, inglês, chinês e dezenas de outros idiomas. A qualidade em português é boa para conversação, programação e análise de documentos.

Comparações

Qwen3.8-27B vs Qwen3.6-35B (MoE): qual escolher?

Qwen3.8-27B (denso): melhor qualidade por parâmetro, melhor em agentes (OSWorld 84,3 vs 63,9). Escolha para raciocínio agêntico de horizonte longo.

Qwen3.6-35B (MoE): 5,3× mais rápido no mesmo hardware (56,6 vs 10,6 tok/s). Escolha para conversa contínua e uso interativo fluido.

Qwen3.8-27B vs GPT-OSS-20B?

O Qwen3.8-27B tem contexto nativo 2× maior (262K vs 128K), multimodalidade nativa, thinking mode e 26 benchmarks publicados. O GPT-OSS-20B é menor e mais rápido (20B total, ~3,6B ativos). Para raciocínio agêntico e contexto longo, o Qwen3.8-27B é superior.

Qwen3.8-27B vs ChatGPT: qual é melhor?

Em benchmarks agênticos, o Qwen3.8-27B (modelo local de 27B) supera as referências do próprio model card: OSWorld 84,3 (vs Opus 4.6 Max 72,7 e Qwen3.7-Plus 73,3), CoWorkBench 70,7 (vs Opus 4.6 Max 68,2). Em conhecimento geral, fica a poucos pontos da fronteira (GPQA 89,2 vs 91,3 do Opus 4.6 Max e 90,3 do Qwen3.7-Plus). A vantagem do Qwen3.8-27B é rodar localmente, com privacidade total e sem custo de API.

Os benchmarks são verificados independentemente?

Não. Todos os 26 benchmarks são reportados pela própria Qwen no model card oficial e ainda não passaram por verificação independente. As colunas de referência (Qwen3.7-Plus, Muse Glimmer-30B, Opus 4.6 Max) vêm do próprio model card da Qwen — servem como ordem de grandeza, não como comparação controlada.
